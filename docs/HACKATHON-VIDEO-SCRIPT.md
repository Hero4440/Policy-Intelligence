## Production Checklist

### Recording
- [ ] Record at 1080p or 4K
- [ ] Ensure all UI text is readable
- [ ] Use smooth transitions (fade between scenes)
- [ ] Cursor visible and moves deliberately
- [ ] Click buttons clearly and pause 1 second to show result

### Voiceover
- [ ] Record in quiet room
- [ ] Speak clearly at 120-140 wpm
- [ ] Match voiceover timing to on-screen action
- [ ] Natural pauses between sentences
- [ ] Edit out mouth clicks and breathing

### Text Overlays
- [ ] White text with dark shadow for contrast
- [ ] Sans-serif font (Inter, Arial), min 24pt
- [ ] Keep on screen 3-5 seconds
- [ ] Don't cover UI elements

### Music
- [ ] Royalty-free background (YouTube Audio Library, Epidemic Sound, Artlist)
- [ ] Uplifting, modern, 60-80 BPM
- [ ] Volume: 20-30% during voiceover, 50% during transitions

### Final Video
- [ ] Duration: 165-180 seconds
- [ ] Format: MP4 (H.264 codec)
- [ ] Resolution: 1920x1080 @ 30fps
- [ ] Audio: 128 kbps AAC

---

## Key Notes

1. **Use live app:** Real PolicyPilot, not mockups
2. **Pre-load data:** Aetna, UHC, Cigna policies ready to compare
3. **Jennifer Kim case:** Use the actual patient/scenario throughout for continuity
4. **Realistic loading:** Let API calls complete (1-2 sec), don't make things instant
5. **Talk through clicks:** Say "Now clicking Compare tab" before you click
6. **Have a fallback:** Screenshots in case of connectivity issues
