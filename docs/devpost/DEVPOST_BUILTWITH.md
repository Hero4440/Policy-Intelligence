# Built With

## Frontend
- **React** - UI framework for building interactive components
- **TypeScript** - Type-safe JavaScript for maintainable code
- **Vite** - Fast build tool and development server
- **CSS3** - Modern styling with custom properties for design system

## Backend
- **Node.js** - Runtime environment for server-side JavaScript
- **TypeScript** - Type safety on the backend
- **Claude API** (Anthropic) - AI-powered semantic search and natural language processing for policy queries

## AI & Intelligence
- **Claude (Anthropic)** - Large language model for:
  - Natural language policy queries
  - Patient readiness assessment
  - Prior authorization requirement analysis
  - Policy document understanding and summarization

## Data & Storage
- **JSON-based data structures** - Policy indices and normalized data
- **File-based storage** - Persistent policy document management

## Development & Testing
- **Vitest** - Unit and integration testing framework
- **Git** - Version control

## Deployment & Infrastructure
- **Railway** *(optional - if using for deployment)*

## Key Integrations
- **Claude MCP Server** - For structured policy queries and patient readiness checking
- **Markdown rendering** - For rich policy documentation display

---

**Total Stack Summary**: A modern full-stack application built with React + TypeScript on the frontend, Node.js on the backend, powered by Claude AI for intelligent policy analysis and understanding.
