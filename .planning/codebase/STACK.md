## Configuration

**Environment:**
- `PORT` (default 3000) - Server port for both MCP and Express
- `NODE_ENV` - Controls production static file serving and dist directory use
- `FHIR_SERVER_URL` (default: https://fhir.promptopinion.ai) - Default FHIR server endpoint
- `OLLAMA_URL` (default: http://127.0.0.1:11434) - Ollama LLM service URL
- `OLLAMA_MODEL` (default: llama3.1) - Model name for Ollama inference
- See `src/mcp/index.ts` line 75, `src/server/index.ts` line 53, `src/server/chat.ts` lines 69-70

**Build:**
- `tsconfig.json` - Target ES2022, module ESNext, strict mode, JSX react-jsx
- `vite.config.ts` - Port 4173, proxy `/api`, `/mcp`, `/health` to http://localhost:3000

**Frontend:**
- `src/frontend/vite-env.d.ts` - Vite type declarations
- `src/frontend/main.tsx` - React entry point
- Frontend built to `dist/` directory (checked at `src/server/index.ts` line 41)

## Platform Requirements

**Development:**
- Node.js 25.6.1 (or compatible LTS)
- npm 11.6.0
- TypeScript 6.0.2 installed globally or via npx
- Optional: Ollama running locally for chat features (http://127.0.0.1:11434)

**Production:**
- Node.js runtime (same as development)
- Static assets built to `dist/` directory
- Optional: FHIR server endpoint (configurable via env var)
- Optional: Ollama service for LLM-based chat responses

**File Storage:**
