<task type="auto">
  <name>Task 2: Create programmatic ngrok deployment script and npm script</name>
  <files>scripts/deploy-ngrok.ts, package.json</files>
  <action>
First, install `@ngrok/ngrok` as a dependency:
```bash
npm install @ngrok/ngrok
```

Create `scripts/deploy-ngrok.ts` that:

1. Imports `ngrok` from `@ngrok/ngrok` and `spawn` from `child_process`
2. Calls `ngrok.forward({ addr: 3000, authtoken_from_env: true })` to start the tunnel
   - Reads `NGROK_AUTHTOKEN` from environment automatically
3. Captures `listener.url()` as `publicUrl`
4. Logs to stderr (not stdout):
   - `Tunnel established: ${publicUrl}`
   - `MCP endpoint: ${publicUrl}/mcp`
   - `Health check: ${publicUrl}/health`
   - `Prompt Opinion connection URL: ${publicUrl}/mcp`
5. Spawns `npx tsx src/mcp/index.ts` as a child process with:
   - `env: { ...process.env, PUBLIC_BASE_URL: publicUrl }`
   - `stdio: 'inherit'`
6. Registers SIGINT handler to kill child process and call `ngrok.disconnect(publicUrl)` then `process.exit(0)`
7. Registers child process `exit` event to also exit the parent

Use `console.error` for all logging (MCP protocol uses stdout for JSON-RPC).

Add to `package.json` scripts:
```json
"deploy:ngrok": "tsx scripts/deploy-ngrok.ts"
```

Do NOT use `npm start` inside the spawn — use `npx tsx src/mcp/index.ts` directly to avoid nested npm process management issues.
  </action>
  <verify>Run `npm run deploy:ngrok` with `NGROK_AUTHTOKEN` set. Verify it prints tunnel URL to stderr, server starts, and ctrl+C cleanly shuts down both processes. If no NGROK_AUTHTOKEN is available, verify the script fails with a clear error message from ngrok SDK.</verify>
  <done>deploy-ngrok.ts starts ngrok tunnel, launches MCP server with PUBLIC_BASE_URL, and cleanly handles shutdown. npm run deploy:ngrok works as single command for hackathon deployment.</done>
</task>
