<task type="auto">
  <name>Task 1: Add per-version text snapshot support with fallback backfill</name>
  <files>src/storage/types.ts, src/storage/policy-store.ts, src/storage/startup.ts</files>
  <action>
    Extend the policy store so every version can provide a text snapshot for side-by-side diff viewing.

    Requirements:
    - persist or derive a stable text snapshot per version
    - do not require raw PDF re-parsing in the browser
    - keep old versions compatible

    Suggested implementation:
    - add a lightweight text-snapshot file per version under policy storage
    - provide helpers:
      - `readPolicyTextSnapshot(policyId, version)`
      - `ensurePolicyTextSnapshot(policyId, version)`
    - snapshot strategy:
      1. if extracted source text exists, use it
      2. otherwise generate a deterministic normalized text projection from the stored `PolicyRecord`
    - during startup or on-demand, backfill missing snapshots for existing stored versions so historical policies are diffable

    The normalized fallback text should preserve the major sections that matter for comparison:
    - title / payer / plan / effective date
    - coverage status
    - preferred and non-preferred products
    - prior auth
    - step therapy
    - indications
    - other requirements
  </action>
  <verify>
    Existing stored policies without raw extracted text can still produce non-empty text snapshots.
    `npx tsc --noEmit` passes.
  </verify>
  <done>
    All stored versions can provide side-by-side text content for the Version Diff page.
  </done>
</task>

<task type="auto">

  <files>src/server/policy-changes.ts, src/server/policy-routes.ts, src/frontend/data/policies.ts</files>
  <action>
    Add a version diff builder and API route.

    In `src/server/policy-changes.ts`, implement:
    - `buildPolicyVersionDiff(policyId, fromVersion, toVersion)`

    Response shape should include:
    - policy metadata
    - `fromVersion`
    - `toVersion`
    - `structuredChanges: ClassifiedDiffField[]`
    - `textSnapshot` object:
      - `leftLabel`
      - `rightLabel`
      - `leftText`
      - `rightText`
    - optional `changedLineHints` or per-line markers if practical, but keep the implementation simple and deterministic

    In `src/server/policy-routes.ts`, add:
    - `GET /api/policies/:policyId/diff?fromVersion=N&toVersion=M`

    In `src/frontend/data/policies.ts`, add:
    - typed interfaces for the Version Diff response
    - `fetchPolicyVersionDiff(policyId, fromVersion, toVersion)`

    Error handling:
    - reject same-version diffs with 400
    - reject unknown version pairs with 404
    - fail clearly if either version file is missing
  </action>
