Pivot the Anton Rx demo from a narrow RA policy browser into a fundamentally stronger policy intelligence workspace that uses the final data package for plan breadth, deterministic comparison logic for trust, and legacy structured policies for deep medical-benefit detail when available.

Output: Hybrid canonical data adapter, Anton Rx REST API, retargeted chat tools, and a workspace UI centered on search, compare, detail, and change watch.
</objective>
