<objective>
Add a true conversational Ask workflow to the Anton Rx demo by introducing a local backend chat service, session-scoped uploads, and an Ollama-backed response loop that can call the existing policy and readiness functions directly.

Purpose: The current frontend can demonstrate static policy browsing, but it cannot support a believable natural-language workflow where a user uploads clinical/policy artifacts and asks follow-up questions. This plan closes that gap without changing the underlying policy tool logic.
Output: Express server entrypoint, chat/upload/session modules, and a rewritten Ask tab that streams grounded answers and inline tool results.
</objective>
