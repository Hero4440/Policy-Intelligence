**data/schemas/policy.schema.ts** — Define the full Zod schema per CONTEXT.md locked decisions:

```typescript
import { z } from 'zod';

const SourceReference = z.object({
  document: z.string(),      // PDF filename
  page: z.number(),           // Page number in PDF
  section: z.string()         // Section header
});

const StepTherapyRequirement = z.object({
  drugName: z.string(),       // e.g., "methotrexate"
  dosage: z.string().optional(), // e.g., "15mg+"
  duration: z.string(),       // e.g., "3 months"
  failureCriteria: z.string(), // e.g., "inadequate response or intolerance"
  evidenceText: z.string(),   // Lightly edited policy quote (1-2 key sentences)
  source: SourceReference
});

const DiagnosisRequirement = z.object({
  icd10Codes: z.array(z.string()), // e.g., ["M05.*", "M06.*"]
  description: z.string(),
  evidenceText: z.string(),
  source: SourceReference
});

const OtherRequirement = z.object({
  category: z.string(),       // e.g., "lab values", "prescriber qualification", "age restriction"
  requirement: z.string(),     // Structured summary
  evidenceText: z.string(),   // Policy quote
  source: SourceReference,
  ambiguous: z.boolean().default(false) // Flag unclear policy language
});

export const PolicyRecordSchema = z.object({
  id: z.string(),              // Unique ID, e.g., "uhc-humira-ra"
  payer: z.enum(['UHC', 'Aetna', 'Cigna']),
  plan: z.string(),            // e.g., "Commercial", "Medicare Advantage"
  drug: z.object({
    brandName: z.string(),
    genericName: z.string(),
    aliases: z.array(z.string()).default([])
  }),
  indication: z.string(),     // "Rheumatoid Arthritis"
  coverageStatus: z.enum(['covered', 'covered-with-pa', 'excluded']),
  paRequired: z.boolean(),
  diagnosisRequirements: z.array(DiagnosisRequirement),
  stepTherapy: z.array(StepTherapyRequirement),
  otherRequirements: z.array(OtherRequirement),
  sourceDocument: z.object({
    filename: z.string(),
    url: z.string().url().optional(),
    retrievalDate: z.string(), // ISO date
    effectiveDate: z.string().optional()
  })
});

export type PolicyRecord = z.infer<typeof PolicyRecordSchema>;
export type StepTherapy = z.infer<typeof StepTherapyRequirement>;
export type DiagnosisReq = z.infer<typeof DiagnosisRequirement>;
export type OtherReq = z.infer<typeof OtherRequirement>;
export type SourceRef = z.infer<typeof SourceReference>;
```

Key schema decisions:
- `paRequired` as separate boolean (quick filter) alongside structured requirements
- `ambiguous` flag on otherRequirements per locked decision
- Evidence text at each requirement level (not just top-level) per locked decision
- Source attribution at each requirement level (document, page, section) per locked decision

**data/lookup/drug-aliases.ts** — Drug name aliasing for RA biologics per locked decisions:

Create a lookup table covering:
- Humira/adalimumab (plus biosimilars: Amjevita, Cyltezo, Hadlima, Hyrimoz)
- Enbrel/etanercept (plus biosimilars: Erelzi, Eticovo)
- Remicade/infliximab (plus biosimilars: Inflectra, Renflexis, Avsola)
- Rinvoq/upadacitinib (JAK inhibitor, no biosimilars)

Export `normalizeDrugName(query: string): string` that accepts any brand name, generic name, or biosimilar name and returns the canonical generic name. Case-insensitive.

Export `drugAliases` record for inspection/testing.

Also export `getDrugInfo(query: string): DrugAlias | undefined` that returns full drug info (brandNames, genericName, class).

**src/extraction/text-cleaner.ts** — Text cleaning pipeline:

Export `cleanPolicyText(rawText: string): string` that:
1. Removes form feed characters (\f)
2. Collapses 3+ newlines to max 2 (paragraph breaks)
3. Collapses 2+ spaces/tabs to single space
4. Trims each line
5. Removes common PDF artifacts (page numbers like "Page X of Y", headers/footers)
6. Final trim

Keep it simple — these are light edits per locked decision. Preserve substance and traceability.

**src/extraction/pdf-extractor.ts** — PDF text extraction:

Export `extractPdfText(pdfPath: string): Promise<string>` that:
1. Reads PDF file from disk using `fs/promises`
2. Extracts text using pdf-parse
3. Runs text through `cleanPolicyText`
4. Returns cleaned text
5. Also logs page count to console

If run directly (as CLI tool via `tsx`), accept PDF path as CLI argument, extract text, and write to `data/policies/extracted/{basename}.txt`.

Export `validatePolicyFile(filePath: string): Promise<PolicyRecord>` — reads JSON file, parses, validates.

If run directly (as CLI tool), accept a JSON file path argument, validate it, and print success/failure.
