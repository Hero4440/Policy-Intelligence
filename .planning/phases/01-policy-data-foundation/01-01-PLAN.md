  <action>
**Schema extension (data/schemas/policy.schema.ts):**

1. Add `BCBS-NC` to the payer enum: `z.enum(['UHC', 'Aetna', 'Cigna', 'BCBS-NC'])`

2. Add a `ProductWithTier` schema above `PolicyRecordSchema`:
```typescript
const ProductWithTier = z.object({
  name: z.string(),
  tier: z.enum(['preferred', 'non-preferred']),
  aliases: z.array(z.string()).default([])
});
```

3. Extend the `drug` object to add an optional `products` array:
```typescript
drug: z.object({
  brandName: z.string(),
  genericName: z.string(),
  aliases: z.array(z.string()).default([]),
  products: z.array(ProductWithTier).optional()  // NEW: oncology preferred/non-preferred
})
```

4. Add optional `indications` field (array of strings) to PolicyRecordSchema for oncology drugs with multiple indications. Keep existing `indication` (singular) field for backward compatibility:
```typescript
indications: z.array(z.string()).optional()  // NEW: multiple indications for oncology
```

5. Add optional `policyTitle` field for richer metadata:
```typescript
policyTitle: z.string().optional()  // NEW: full policy title from document
```

6. Export new types: `ProductWithTier` type alias.

**Drug aliases (data/lookup/drug-aliases.ts):**

7. Add bevacizumab family entry to `drugAliases`:

  class: 'VEGF inhibitor'
