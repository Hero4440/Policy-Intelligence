<task type="auto">
  <name>Task 1: Implement patient case file store</name>
  <files>src/storage/patient-store.ts</files>
  <action>
    Create `src/storage/patient-store.ts`. Patient case IDs are UUIDs (per CONTEXT.md decision). Use `crypto.randomUUID()` (Node.js built-in, no import needed in ESM). Use only `fs` and `path` — no extra libraries.

    **casePath(caseId: string): string** — returns `{PATIENTS_DIR}/{caseId}` (the case folder path).

    **createPatientCase(input: { payer: string; requestedDrug: string; diagnosis: string; patientName: string }): PatientCase**:
    1. `caseId = crypto.randomUUID()`.
    2. `mkdirSync(casePath(caseId), { recursive: true })`.
    3. Build `PatientCase` object: status = `'missing-docs'`, createdAt = updatedAt = ISO now, documentFiles = [], extractedFactsFile = undefined.
    4. Write `case.json` inside the case folder via `writeFileSync(join(casePath(caseId), 'case.json'), JSON.stringify(patientCase, null, 2), 'utf-8')`.
    5. Return the PatientCase object.

    **getPatientCase(caseId: string): PatientCase | null**:
    - Read and parse `{casePath(caseId)}/case.json`. Return null if file doesn't exist or JSON is malformed (catch parse errors, log with `console.error('[patient-store]', ...)`).

    **listPatientCases(): PatientCase[]**:
    - `readdirSync(PATIENTS_DIR, { withFileTypes: true })` — filter to directories only.
    - For each dir, call `getPatientCase(dir.name)` and collect non-null results.
    - Return sorted by `createdAt` descending.
    - If `PATIENTS_DIR` doesn't exist or is empty, return `[]`.

    **addCaseDocument(caseId: string, fileName: string, content: Buffer | Uint8Array): string**:
    1. Ensure case folder exists: `mkdirSync(casePath(caseId), { recursive: true })`.
    2. Sanitize `fileName`: replace `[^a-zA-Z0-9._-]` with `-`.
    3. Write file: `writeFileSync(join(casePath(caseId), sanitizedFileName), content)`.
    4. Load case.json via `getPatientCase(caseId)` — if null throw `Error('Case not found: ' + caseId)`.
    5. Add sanitizedFileName to `documentFiles` if not already present.
    6. Set `updatedAt = ISO now`.
    7. Re-write case.json.
    8. Return the full file path.

    **updateCaseStatus(caseId: string, status: PatientCase['status']): PatientCase | null**:
    - Load case, update `status` and `updatedAt`, re-write case.json, return updated case. Return null if case not found.

    Import types from `./types.js` and paths from `./paths.js`.
    Use `ensureDataDirectories()` at the top of `createPatientCase` to ensure the patients/ root exists.
  </action>
  <verify>
    ```bash
    npx tsx -e "
    import { createPatientCase, getPatientCase, listPatientCases, addCaseDocument, updateCaseStatus } from './src/storage/patient-store.ts';
    import { writeFileSync } from 'fs';
    const c = createPatientCase({ payer: 'Cigna', requestedDrug: 'Herceptin', diagnosis: 'Breast Cancer', patientName: 'Jane Test' });
    console.log('created:', c.caseId, c.status);
    const found = getPatientCase(c.caseId);
    console.log('found:', !!found, found?.patientName);
    addCaseDocument(c.caseId, 'clinical note.pdf', Buffer.from('fake note'));
    const updated = updateCaseStatus(c.caseId, 'ready-for-eval');
    console.log('status:', updated?.status, 'docs:', updated?.documentFiles.length);
    const list = listPatientCases();
    console.log('list length:', list.length);
    "
    ```
    Expected: created: <uuid> missing-docs, found: true Jane Test, status: ready-for-eval docs: 1, list length: 1 (or more)
  </verify>
  <done>
    - createPatientCase creates case folder + case.json with UUID ID
    - getPatientCase reads and parses case.json, returns null for missing cases
    - addCaseDocument writes file + updates documentFiles in case.json
    - updateCaseStatus updates status + updatedAt in case.json
    - listPatientCases returns all cases sorted descending by createdAt
    - Zero TypeScript compile errors
  </done>

<task type="auto">
  <name>Task 2: Implement evaluation file store</name>
  <files>src/storage/evaluation-store.ts</files>
  <action>
    Create `src/storage/evaluation-store.ts`. Evaluation IDs are UUIDs. Each evaluation is a flat JSON file: `data/evaluations/{evalId}.json`. Use only `fs` and `path`.

    **saveEvaluation(input: Omit<CoverageEvaluation, 'evalId' | 'evaluatedAt'>): CoverageEvaluation**:
    1. `evalId = crypto.randomUUID()`.
    2. `evaluatedAt = ISO now`.
    3. Build full `CoverageEvaluation` object.
    4. Call `ensureDataDirectories()`.
    5. Write `{EVALUATIONS_DIR}/{evalId}.json` via `writeFileSync`.
    6. Return the evaluation object.

    **getEvaluation(evalId: string): CoverageEvaluation | null**:
    - Build path `{EVALUATIONS_DIR}/{evalId}.json`.
    - Return null if file doesn't exist.
    - Parse and return. Catch JSON parse errors → log `console.error('[evaluation-store] malformed:', evalId, err.message)` → return null.

    **listEvaluations(filter?: { caseId?: string; policyId?: string }): CoverageEvaluation[]**:
    - `readdirSync(EVALUATIONS_DIR)` filtered to `*.json` files.
    - Read and parse each file via `getEvaluation(basename without .json)`.
    - Apply optional filter: if `filter.caseId` provided, keep only matching; same for `filter.policyId`.
    - Return sorted by `evaluatedAt` descending.
    - If EVALUATIONS_DIR doesn't exist or is empty, return `[]`.

    Import types from `./types.js` and paths from `./paths.js`.
  </action>
  <verify>
    ```bash
    npx tsx -e "
    import { saveEvaluation, getEvaluation, listEvaluations } from './src/storage/evaluation-store.ts';
    const ev = saveEvaluation({
      caseId: 'test-case-1', policyId: 'cigna-herceptin', policyVersion: 1,
      coverageStatus: 'PA Required',
      checklist: [{ criterion: 'Prior Auth Required', status: 'PASS' }]
    });
    console.log('saved:', ev.evalId, ev.coverageStatus);
    const found = getEvaluation(ev.evalId);
    console.log('found:', !!found, found?.coverageStatus);
    const missing = getEvaluation('00000000-0000-0000-0000-000000000000');
    console.log('missing:', missing);
    const list = listEvaluations({ caseId: 'test-case-1' });
    console.log('list length:', list.length);
    "
    ```
    Expected: saved: <uuid> PA Required, found: true PA Required, missing: null, list length: 1
  </verify>
  <done>
    - saveEvaluation writes data/evaluations/{uuid}.json and returns full evaluation object
    - getEvaluation returns evaluation by ID, null for missing/malformed files
    - listEvaluations returns all evaluations with optional caseId/policyId filter
    - Zero TypeScript compile errors
  </done>
</task>
