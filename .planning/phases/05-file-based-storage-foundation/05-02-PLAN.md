    Create `src/storage/policy-store.ts`. Use only Node.js built-in `fs` and `path` — no additional libraries needed.

    **Policy ID derivation** (per CONTEXT.md — human-readable, predictable):
    ```ts
    export function derivePolicyId(record: PolicyRecord): string {
      // Slugify: "{payer}-{drugBrandName}" → lowercase, spaces→hyphens, strip non-alphanum
      const payer = record.payer.toLowerCase().replace(/[^a-z0-9]+/g, '-');
      const drug  = record.drug.brandName.toLowerCase().replace(/[^a-z0-9]+/g, '-');
      return `${payer}-${drug}`;
    }
    ```

    **writePolicyVersion(record: PolicyRecord): { version: number; filePath: string; diffRecord: DiffRecord | null }**
    1. Call `ensureDataDirectories()` (idempotent).
    2. Derive `policyId` via `derivePolicyId(record)`.
    3. Load current index via `loadIndex()` (returns `PolicyIndex`, creates empty if missing).
    4. Determine next version: if entry exists, `nextVersion = currentVersion + 1`, else `nextVersion = 1`.
    5. Write versioned file: `{POLICIES_STRUCTURED_DIR}/{policyId}_v{nextVersion}.json` using `writeFileSync`.
    6. If `nextVersion > 1`, compute diff against previous version file and write diff record to `{POLICIES_STRUCTURED_DIR}/{policyId}_diff_v{nextVersion-1}_to_v{nextVersion}.json`.
    7. Update index entry (or create new) then call `saveIndex(index)` which does atomic write (temp file + `renameSync`).
    8. Return `{ version: nextVersion, filePath, diffRecord }`.

    **Atomic index write (saveIndex)**:
    ```ts
    function saveIndex(index: PolicyIndex): void {
      const tmp = POLICY_INDEX_PATH + '.tmp';
      writeFileSync(tmp, JSON.stringify(index, null, 2), 'utf-8');
      renameSync(tmp, POLICY_INDEX_PATH);
    }
    ```

    **loadIndex(): PolicyIndex**:
    - If `POLICY_INDEX_PATH` doesn't exist, return `{ updatedAt: now(), policies: [] }`.
    - Otherwise `JSON.parse(readFileSync(...))`.

    **readPolicyVersion(policyId: string, version: number): PolicyVersion | null**:
    - Construct filename `{policyId}_v{version}.json`, read from `POLICIES_STRUCTURED_DIR`, parse and return. Return null if file doesn't exist.

    **readCurrentPolicy(policyId: string): PolicyRecord | null**:
    - Load index, find entry, read `currentVersionFile`, parse `.record` field.

    **listPolicyIndex(): PolicyIndexEntry[]**:
    - Load index, return `.policies`.

    **diffPolicyVersions(policyId, fromVersion, toVersion): DiffRecord | null**:
    - Load diff file `{policyId}_diff_v{from}_to_v{to}.json` if it exists, parse and return. Return null if not found.

    **Diff computation** (called internally by writePolicyVersion):
    ```ts
    function computeDiff(oldRecord: PolicyRecord, newRecord: PolicyRecord): DiffField[] {
      // Flat comparison of top-level scalar fields and JSON-stringified sub-objects
      // Fields to compare: payer, plan, policyTitle, indication, coverageStatus, paRequired
      // Plus JSON.stringify comparison for: drug, indications, diagnosisRequirements, stepTherapy, otherRequirements, sourceDocument
      // A change is detected when JSON.stringify(oldVal) !== JSON.stringify(newVal)
    }
    ```

    **Malformed file handling**: Any JSON.parse that throws should be caught, logged with `console.error('[policy-store] malformed file:', filePath, err.message)`, and the function should return null (never throw to callers).

    Import all types from `./types.js` and path constants from `./paths.js`.
    Use `renameSync` from `'fs'` (not `fs/promises`) to keep all index operations synchronous and safe.
