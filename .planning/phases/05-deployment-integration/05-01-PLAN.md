  <name>Task 1: Add remote-client deployment hardening to the MCP server</name>
  <files>
    src/mcp/index.ts
    package.json
  </files>
  <action>
Update `src/mcp/index.ts` so the current Streamable HTTP server is safe for Prompt Opinion's browser-based client path.

Implementation requirements:
- Add Express CORS middleware with `origin: true`, `credentials: true`, `methods: ['GET', 'POST', 'OPTIONS']`, and `exposedHeaders: ['Mcp-Session-Id']`
- Keep the existing stateless `StreamableHTTPServerTransport({ sessionIdGenerator: undefined })`
- Preserve `GET /health` and `POST /mcp`
- Ensure the health response includes enough detail for deployment debugging (status, tool count, policy count, and timestamp)
- Keep startup logs on stderr only

Update `package.json` with any minimal dependency or script changes needed to support the smoke verification flow. Do not introduce a full deployment platform yet; this plan is specifically the fast-path demo deployment via local server + HTTPS tunnel.
  </action>
  <verify>
Run:
```bash
npx tsc --noEmit
npm start
curl http://localhost:3000/health
curl -X POST http://localhost:3000/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'
```
Confirm health returns status `ok` and tools/list returns all three tools.
  </verify>
  <done>
The local MCP server starts cleanly, answers `/health`, and responds to `tools/list` without CORS-related omissions or protocol issues. The code remains stateless and compatible with remote HTTP deployment.
  </done>
</task>

- Print a concise pass/fail summary and exit non-zero on failure

Create `docs/prompt-opinion/deployment-runbook.md` documenting:
- Local startup (`npm start`)
- Local verification (`npx tsx tests/mcp/smoke-remote-server.ts`)
- ngrok tunnel startup (`ngrok http 3000`)
- Which exact URLs to copy into Prompt Opinion (`https://.../mcp` and `https://.../health`)
- Common failure modes from research: CORS issues, health checks pointed at `/mcp`, ngrok URL rotation, and missing SHARP toggle later in Prompt Opinion
- A short "demo-day checklist" section so execution can be repeated quickly under time pressure
