  <action>
Create `src/server/evidence-search.ts` exporting:

```ts
export interface EvidenceSearchResult {
  policyId: string;
  policyTitle: string;
  payer: string;
  drugFamily: string;
  version: number;
  fieldLabel: string;       // e.g. "Step Therapy", "Diagnosis Requirement", "Other Requirement"
  snippet: string;          // The evidence text
  document: string;         // Source filename
  page: number | null;      // Page number in PDF
  section: string;          // Section heading
}

export function searchPolicyEvidence(query: string): EvidenceSearchResult[]
```

Implementation of `searchPolicyEvidence`:
1. Normalize query: `query.trim().toLowerCase()` — if empty string after trim, return `[]`
2. Load policy index via `listPolicyIndex()` from `src/storage/policy-store.ts`
3. For each policy in the index, load the current version record via `readPolicyVersion(policyId, currentVersion)`
4. Extract evidence snippets from the `PolicyRecord` across all evidence-bearing fields:
   - `record.diagnosisRequirements[]` — `evidenceText` field, `source.document`, `source.page`, `source.section`, fieldLabel = "Diagnosis Requirement"
   - `record.stepTherapy[]` — `evidenceText` field, `source.document`, `source.page`, `source.section`, fieldLabel = "Step Therapy"
   - `record.otherRequirements[]` — `evidenceText` field, `source.document`, `source.page`, `source.section`, fieldLabel = `item.category || "Other Requirement"`
5. For each extracted snippet, check if `snippet.toLowerCase().includes(query)` OR `section.toLowerCase().includes(query)` OR `fieldLabel.toLowerCase().includes(query)` — if any match, add an `EvidenceSearchResult` to results
6. Deduplicate results by `(policyId + snippet)` to avoid duplicates from multiple requirement items with identical text
7. Sort results: exact snippet matches first, then section matches, then field matches — use a simple score: +2 for snippet match, +1 for section match, +1 for fieldLabel match; sort descending
8. Return results array (no artificial limit — caller can paginate if needed)

Use `import { listPolicyIndex, readPolicyVersion } from '../storage/policy-store.js'`. Do NOT use LLM — this is deterministic keyword search per CONTEXT.md locked decision.
