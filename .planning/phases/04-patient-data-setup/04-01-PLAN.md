**CRITICAL — Payer name alignment:**
Policy store uses `payer: "UHC"` and `payer: "Aetna"`. FHIR extractor reads `payor[0].display`. Set Coverage.payor[0].display to EXACTLY "UHC" for patients 1 and 2, and "Aetna" for patient 3 so check_patient_readiness can match to policies.

**CRITICAL — Extractor compatibility:**
The extractors in `src/mcp/fhir/extractors.ts` expect:
- Condition resources with `code.coding[].system` matching one of: `http://hl7.org/fhir/sid/icd-10`, `http://hl7.org/fhir/sid/icd-10-cm`, `http://www.cms.gov/Medicare/Coding/ICD10`
- MedicationRequest resources with `medicationCodeableConcept.coding[]` (prefer RxNorm system `http://www.nlm.nih.gov/research/umls/rxnorm`)
- Coverage resources with `payor[0].display` for payer name, and `class[].type.coding[0].code === "plan"` for plan name
- Each resource as `entry[].resource` in the Bundle
