   ```typescript
   interface StandardToolResponse {
     answer: string;
     structured_result: Record<string, unknown>;
     evidence: EvidenceItem[];
     confidence: 'HIGH' | 'MEDIUM' | 'LOW';
   }
   ```

2. **EvidenceItem interface:**
   ```typescript
   interface EvidenceItem {
     field: string;          // Which field this evidence supports
     text: string;           // 1-3 sentence snippet from policy
     source: {
       policy_id: string;
       policy_title: string;
       effective_date?: string;
       page: number;
       section: string;
     };
   }
   ```

3. **buildStandardResponse():** Takes answer string, structured_result object, evidence array, and confidence level. Returns MCP-compatible `{ content: [{ type: 'text', text: JSON.stringify(response, null, 2) }] }` format.

4. **buildErrorResponse():** Takes error message and suggestions object (available_payers, available_drugs, hint). Returns same MCP content format with error shape: `{ error: string, message: string, suggestions: {...}, hint: string }`. Per user decision: include helpful suggestions like "Drug X not found. Did you mean: bevacizumab, rituximab?"

Per user decision: full citation includes policy title, effective date, and section/page.

3. **formatSourceCitation(policy: PolicyRecord):** Returns `{ policy_id, policy_title, effective_date }` object for use in evidence items.

**Create `src/mcp/tools/list_policies.ts`:**

Follow exact pattern from `get_drug_coverage.ts` — export a `registerListPolicies(server: McpServer)` function.

Tool registration:
- Name: `'list_policies'`
- Description: "List all loaded medical policy documents with metadata. Returns payer name, policy title, effective date, and covered drug families for each policy. Use this tool to discover what policies are available before querying for details or comparisons. Optionally filter by payer name or drug family. Accepts brand names, generic names, or biosimilar names for drug filtering."
- inputSchema: `listPoliciesInput.shape`

Handler implementation:
1. Get `payer` and `drug_family` from params
2. Call `getAllPolicies()` from policy store
3. If `payer` provided: filter case-insensitively. Use `payer.toLowerCase()` matching against `p.payer.toLowerCase()`. Also handle partial match (e.g., "bcbs" matches "BCBS-NC") by checking `.includes()`.
4. If `drug_family` provided: normalize via `normalizeDrugName(drug_family)` then filter by `p.drug.genericName.toLowerCase() === normalized.toLowerCase()`.
5. Map filtered policies to metadata objects: `{ policy_id, payer, policy_title (from policyTitle || sourceDocument.filename), effective_date (from sourceDocument.effectiveDate), drug_family (from drug.genericName), drug_brand (from drug.brandName), indications (from indications || [indication]) }`.
6. Build human-readable answer: `"Found {N} polic{y/ies}{filter description}. Payers: {unique payers}. Drug families: {unique drugs}."`
7. Return via `buildStandardResponse(answer, { total_count, policies: metadata }, [], 'HIGH')`. Evidence array is empty for list operations (no field-level evidence). Confidence is always HIGH for deterministic list.
8. If zero results after filtering: return via `buildErrorResponse()` with message "No policies match filters", available_payers and available_drugs from full unfiltered set, and hint suggesting valid filter values.
