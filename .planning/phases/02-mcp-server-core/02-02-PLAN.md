       - Tool name: "check_patient_readiness"
       - Description: "Analyze a patient's clinical context against a health plan's prior authorization criteria for a specific drug. Returns which PA requirements the patient appears to meet, which are missing or unverifiable, and what documentation may still be needed. Use this tool after identifying that a drug requires prior auth, to assess whether a specific patient is likely to meet the approval criteria. Note: Full patient context integration via FHIR is coming in a future update — currently returns the criteria checklist that would be evaluated."
       - Input schema: plan (string), drug (string), patient_context (passthrough object)
       - Handler logic:
         a. Normalize drug name, find policy
         b. If no policy found, return error
         c. Extract all requirements from the policy into a checklist:
            - For each diagnosisRequirement: { criterion: description, category: "diagnosis", status: "requires_patient_data", evidence: evidenceText }
            - For each stepTherapy: { criterion: drugName + duration, category: "step_therapy", status: "requires_patient_data", evidence: evidenceText }
            - For each otherRequirement: { criterion: requirement, category: category, status: "requires_patient_data", evidence: evidenceText }
         d. Build response: { drug: { brand, generic }, payer, plan, readiness_status: "pending_patient_context", message: "Patient context integration pending. Below are the prior authorization criteria that would be checked against the patient's clinical data.", criteria_checklist: [...], total_criteria: N, note: "Full FHIR patient context matching will be available in a future update. For now, use this checklist to manually assess patient readiness." }
         e. Return as JSON text content

    2. Update `src/mcp/index.ts`:
       - Import and call `registerCheckPatientReadiness(server)`
       - Update /health endpoint tool count to 3
       - No other changes needed — server infrastructure from Plan 01 handles everything
