  <name>Task 1: Implement get_policy_evidence MCP tool</name>
  <files>src/mcp/tools/get_policy_evidence.ts</files>
  <action>
Create `src/mcp/tools/get_policy_evidence.ts` exporting `registerGetPolicyEvidence(server: McpServer): void`.

Tool name: `get_policy_evidence`
Description: "Retrieve evidence snippets for a specific policy. Optionally filter by field label (e.g., 'prior_auth', 'step_therapy', 'diagnosis_requirements', 'other_requirements'). Every result includes policy name, payer, page, section, and the exact evidence text. Use this when you need source-grounded evidence for a specific policy's criteria."

Input schema:
```
{
  policy_id: z.string().describe("Policy ID — use list_policies or list_policy_versions to find IDs"),
  version: z.number().int().optional().describe("Version number (omit for current version)"),
  field_filter: z.string().optional().describe("Filter by field label: 'diagnosis_requirements', 'step_therapy', 'other_requirements', or a substring match")
}
```

Implementation:
1. Call `listPolicyIndex()` from `../../storage/policy-store.js`. Find entry for policy_id. If not found, return buildErrorResponse listing available policy IDs.
2. Determine version to use: `version ?? entry.currentVersion`.
3. Call `readPolicyVersion(policy_id, resolvedVersion)`. If null, return buildErrorResponse.
4. Collect all evidence from the PolicyRecord (record = policyVersion.record):
   - diagnosisRequirements: `record.diagnosisRequirements.map(item => ({ fieldLabel: 'diagnosis_requirements', snippet: item.evidenceText, document: item.source.document, page: item.source.page, section: item.source.section }))`
   - stepTherapy: `record.stepTherapy.map(item => ({ fieldLabel: 'step_therapy', snippet: item.evidenceText, document: item.source.document, page: item.source.page, section: item.source.section }))`
   - otherRequirements: `record.otherRequirements.map(item => ({ fieldLabel: item.category || 'other_requirements', snippet: item.evidenceText, document: item.source.document, page: item.source.page, section: item.source.section }))`
5. If field_filter provided, filter results: keep items where `item.fieldLabel.toLowerCase().includes(field_filter.toLowerCase())`.
6. Build response:
   - human_readable: `"Found ${filtered.length} evidence item(s) for ${record.policyTitle ?? record.indication} (${record.payer}), version ${resolvedVersion}${field_filter ? `, field: ${field_filter}` : ''}."`
   - structured_result: `{ policyId: policy_id, policyTitle: record.policyTitle ?? record.indication, payer: record.payer, version: resolvedVersion, evidenceCount: filtered.length, evidence: filtered.map(e => ({ fieldLabel: e.fieldLabel, snippet: e.snippet, document: e.document, page: e.page, section: e.section })) }`
   - evidence: filtered.slice(0, 10).map(e => ({ field: e.fieldLabel, text: e.snippet, source: { policy_id, policy_title: record.policyTitle ?? record.indication, page: e.page ?? 0, section: e.section } }))
   - confidence: filtered.length > 0 ? 'HIGH' : 'LOW'

Import `listPolicyIndex`, `readPolicyVersion` from `../../storage/policy-store.js`. Import `buildStandardResponse`, `buildErrorResponse` from `../utils/response_builder.js`.
  </action>

<task type="auto">
  <name>Task 2: Implement search_policy_rules MCP tool</name>
  <files>src/mcp/tools/search_policy_rules.ts</files>
  <action>
Create `src/mcp/tools/search_policy_rules.ts` exporting `registerSearchPolicyRules(server: McpServer): void`.

Tool name: `search_policy_rules`
Description: "Keyword search across all loaded policy rules and evidence snippets. Returns ranked results showing which policies contain matching evidence. Every result includes policy name, payer, page, section heading, snippet text, and field label. Use this to find which payers have rules matching a clinical concept (e.g., 'step therapy', 'prior authorization', 'rituximab', 'bevacizumab')."

Input schema:
```
{
  query: z.string().describe("Keyword or phrase to search across all policy evidence"),
  limit: z.number().int().min(1).max(50).optional().default(20).describe("Maximum number of results to return (default 20, max 50)")
}
```

Implementation:
1. Validate query is non-empty string. Return buildErrorResponse if empty.
2. Call `searchPolicyEvidence(query)` from `../../server/evidence-search.js`. This returns `EvidenceSearchResult[]` — already ranked by relevance score.
3. Slice to `limit` (default 20).
4. Build response:
   - human_readable: `"Found ${results.length} evidence result(s) for '${query}' across ${uniquePolicies} policy source(s). Top match: ${results[0]?.policyTitle ?? 'N/A'} (${results[0]?.payer ?? ''})."`
   - structured_result: `{ query, totalResults: results.length, uniquePolicies, results: results.map(r => ({ policyId: r.policyId, policyTitle: r.policyTitle, payer: r.payer, drugFamily: r.drugFamily, version: r.version, fieldLabel: r.fieldLabel, snippet: r.snippet, document: r.document, page: r.page, section: r.section })) }`
   - evidence: results.slice(0, 10).map(r => ({ field: r.fieldLabel, text: r.snippet, source: { policy_id: r.policyId, policy_title: r.policyTitle, page: r.page ?? 0, section: r.section } }))
   - confidence: results.length > 5 ? 'HIGH' : results.length > 0 ? 'MEDIUM' : 'LOW'
5. `uniquePolicies` = `new Set(results.map(r => r.policyId)).size`
6. Wrap in try/catch → buildErrorResponse on failure.

Import `searchPolicyEvidence` from `../../server/evidence-search.js`. Import `buildStandardResponse`, `buildErrorResponse` from `../utils/response_builder.js`.

Do NOT implement any search logic — delegate entirely to searchPolicyEvidence which already handles keyword scoring and deduplication.
