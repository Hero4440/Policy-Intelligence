Tool name: `extract_patient_facts`
Description: "Retrieve structured patient facts for a case. Returns diagnosis, requested drug, prior therapies, prescriber type, insurance/payer info, and any clinical notes — each with their source document reference and confidence. Use this before running evaluate_patient_against_policy to understand what facts are available."

Input schema:
```
{
  case_id: z.string().describe("Patient case ID — use list_patient_cases or get_case_summary to find IDs")
}
```

Implementation:
1. Call `getPatientCase(case_id)` from `../../storage/patient-store.js`. If null, return buildErrorResponse("Patient case not found", { hint: "Use get_case_summary or the portal /api/patients/cases endpoint to find valid case IDs." }).
2. The PatientCase has `extractedFacts: PatientFactRecord[]` (category: 'diagnosis' | 'medication' | 'coverage' | 'requested_drug' | 'payer' | 'prescriber' | 'prior_therapy' | 'insurance' | 'clinical_note').
3. Group facts by category: build a categorized summary object.
4. Build structured_result:
```
{
  caseId: patientCase.caseId,
  patientName: patientCase.patientName,
  payer: patientCase.payer,
  requestedDrug: patientCase.requestedDrug,
  diagnosis: patientCase.diagnosis,
  caseStatus: patientCase.status,
  extractedFacts: patientCase.extractedFacts ?? [],
  factsByCategory: {
    diagnosis: facts filtered by category === 'diagnosis',
    requestedDrug: facts filtered by category === 'requested_drug',
    priorTherapies: facts filtered by category === 'prior_therapy',
    prescriber: facts filtered by category === 'prescriber',
    insurance: facts filtered by category === 'insurance' or 'payer' or 'coverage',
    clinicalNotes: facts filtered by category === 'clinical_note'
  },
  documentCount: patientCase.documents?.length ?? patientCase.documentFiles.length
}
```
5. answer: `"Patient case ${case_id} (${patientCase.patientName}): ${(patientCase.extractedFacts ?? []).length} extracted facts across ${documentCount} document(s). Diagnosis: ${patientCase.diagnosis}. Drug: ${patientCase.requestedDrug}. Payer: ${patientCase.payer}. Status: ${patientCase.status}."`
6. evidence: (patientCase.extractedFacts ?? []).slice(0, 10).map(f => ({ field: f.category, text: f.evidenceSnippet ?? f.value, source: { policy_id: '', policy_title: patientCase.patientName, page: 0, section: f.label } }))
7. confidence: `(patientCase.extractedFacts ?? []).length > 3 ? 'HIGH' : (patientCase.extractedFacts ?? []).length > 0 ? 'MEDIUM' : 'LOW'`

Import `getPatientCase` from `../../storage/patient-store.js`. Import `buildStandardResponse`, `buildErrorResponse` from `../utils/response_builder.js`.

<task type="auto">
  <name>Task 2: Implement evaluate_patient_against_policy MCP tool</name>
  <files>src/mcp/tools/evaluate_patient_against_policy.ts</files>
  <action>
Create `src/mcp/tools/evaluate_patient_against_policy.ts` exporting `registerEvaluatePatientAgainstPolicy(server: McpServer): void`.

Tool name: `evaluate_patient_against_policy`
Description: "Run a coverage evaluation for a patient case against a specific policy version. Returns coverage status (Covered / PA Required / Likely Eligible but Docs Missing / Not Covered / Preferred Alternative Required / Unclear) and a full requirement checklist with PASS/MISSING/UNKNOWN/NEEDS REVIEW labels. Evidence links connect each checklist item to the source policy evidence. The evaluation is saved and retrievable by evalId."

Input schema:
```
{
  case_id: z.string().describe("Patient case ID"),
  policy_id: z.string().describe("Policy ID to evaluate against"),
  policy_version: z.number().int().optional().describe("Policy version (omit for current version)")
}
```

Implementation:
1. Call `getPatientCase(case_id)` from `../../storage/patient-store.js`. If null, return buildErrorResponse.
2. Call `listPolicyIndex()` from `../../storage/policy-store.js`. Find entry for policy_id. If not found, return buildErrorResponse listing available policy IDs.
3. Determine resolvedVersion = `policy_version ?? entry.currentVersion`.
4. CRITICAL — the function signature is object-based, not positional. Call it exactly as:
   ```typescript
   const evaluationPayload = evaluatePatientCaseAgainstPolicy({
     caseId: case_id,
     policyId: policy_id,
     policyVersion: resolvedVersion
   });
   ```
   This function signature is `evaluatePatientCaseAgainstPolicy(input: { caseId: string; policyId: string; policyVersion: number }): CaseEvaluationPayload`.
   It THROWS on error (case not found, policy version not found) — wrap in try/catch and return buildErrorResponse on catch.
   It returns `CaseEvaluationPayload` which is `Omit<CoverageEvaluation, 'evalId' | 'evaluatedAt'>` — it does NOT include evalId or evaluatedAt. `saveEvaluation` is therefore ALWAYS required to get a persisted record with those fields.
5. Call `saveEvaluation(evaluationPayload)` from `../../storage/evaluation-store.js` to persist. This returns the saved `CoverageEvaluation` with `evalId` and `evaluatedAt` populated.
6. Build response using `evaluation` (the saved result from saveEvaluation):
   - answer: `"Coverage evaluation for ${patientCase.patientName} against ${entry.title} (${entry.payer}): ${evaluation.coverageStatus}. ${evaluation.checklist.filter(i => i.status === 'PASS').length} criteria PASS, ${evaluation.checklist.filter(i => i.status === 'MISSING').length} MISSING, ${evaluation.checklist.filter(i => i.status === 'UNKNOWN').length} UNKNOWN. EvalId: ${evaluation.evalId}."`
   - structured_result: `{ evalId: evaluation.evalId, caseId: evaluation.caseId, policyId: evaluation.policyId, policyVersion: evaluation.policyVersion, policyTitle: evaluation.policyTitle, payer: evaluation.payer, coverageStatus: evaluation.coverageStatus, evaluatedAt: evaluation.evaluatedAt, checklistSummary: { total: evaluation.checklist.length, pass: ..., missing: ..., unknown: ..., needsReview: ... }, checklist: evaluation.checklist.map(item => ({ criterion: item.criterion, category: item.category, status: item.status, rationale: item.rationale, policyEvidence: { document: item.policyEvidence.document, page: item.policyEvidence.page, section: item.policyEvidence.section, snippet: item.policyEvidence.snippet } })) }`
   - evidence: evaluation.checklist.slice(0, 10).map(item => ({ field: item.criterion, text: item.policyEvidence.snippet, source: { policy_id: evaluation.policyId, policy_title: evaluation.policyTitle ?? '', page: item.policyEvidence.page ?? 0, section: item.policyEvidence.section } }))
   - confidence: evaluation.coverageStatus === 'Covered' || evaluation.coverageStatus === 'Not Covered' ? 'HIGH' : 'MEDIUM'
7. Wrap full handler in try/catch → buildErrorResponse on error.

Import `getPatientCase` from `../../storage/patient-store.js`. Import `listPolicyIndex` from `../../storage/policy-store.js`. Import `evaluatePatientCaseAgainstPolicy` from `../../server/patient-evaluation.js`. Import `saveEvaluation` from `../../storage/evaluation-store.js`. Import `buildStandardResponse`, `buildErrorResponse` from `../utils/response_builder.js`.

Note: `buildStandardResponse` takes (answer, structured_result, evidence, confidence) — the first argument is `answer` (not `human_readable`). Match the StandardToolResponse interface in response_builder.ts exactly.
