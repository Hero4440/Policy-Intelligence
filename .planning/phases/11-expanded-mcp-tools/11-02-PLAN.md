Tool name: `diff_policy_versions`
Description: "Return a structured field-level diff between two versions of a policy. Each changed field includes: field name, old value, new value, change type (added/removed/updated), and severity (cosmetic/operational/clinical). Use this to understand what changed when a policy was updated."

Input schema:
```
{
  policy_id: z.string().describe("Policy ID"),
  from_version: z.number().int().describe("Older version number"),
  to_version: z.number().int().describe("Newer version number")
}
```

Implementation:
1. Import `buildPolicyVersionDiff`, `getPolicyChangeEvent` from `../../server/policy-changes.js`.

   CRITICAL — understand the actual return types before writing code:
   - `buildPolicyVersionDiff(policyId, fromVersion, toVersion)` returns `PolicyVersionDiffPayload`, which has:
     - `policyId`, `policyTitle`, `payer`, `drugFamily`, `fromVersion`, `toVersion`
     - `structuredChanges: ClassifiedDiffField[]` (NOT `changes` — that field does not exist on this type)
     - `textSnapshot: { leftLabel, rightLabel, leftText, rightText }`
     - NO `timestamp`, `summary`, or `severityCounts` at the top level
   - `buildPolicyVersionDiff` THROWS (never returns null) when: versions are identical, policy not found, or version pair not found. There is no null return path — do NOT add a null check.
   - `getPolicyChangeEvent(policyId, fromVersion, toVersion)` returns `PolicyChangeEvent | null`, and PolicyChangeEvent DOES have `timestamp`, `summary`, and `severityCounts`.

2. Wrap the entire handler in try/catch. On any thrown error, return `buildErrorResponse(err.message, { hint: 'Use list_policy_versions to find available version numbers.' })`.

3. Call `buildPolicyVersionDiff(policy_id, from_version, to_version)` — assign to `result`.

4. Also call `getPolicyChangeEvent(policy_id, from_version, to_version)` to get the event with summary/severityCounts/timestamp — assign to `event`. If event is null, derive these manually:
   - Derive severityCounts from result.structuredChanges:
     ```typescript
     const severityCounts = result.structuredChanges.reduce(
       (acc, c) => { acc[c.severity] = (acc[c.severity] ?? 0) + 1; return acc; },
       {} as Record<string, number>
     );
     ```
   - summary: `"Version update introduced changes."`
   - timestamp: `new Date().toISOString()`

5. If `result.structuredChanges.length === 0`, build response with:
   - answer: `"No field-level changes detected between v${from_version} and v${to_version}. Changes may be cosmetic (whitespace/formatting only)."`
   - structured_result: `{ policyId: result.policyId, policyTitle: result.policyTitle, payer: result.payer, fromVersion: result.fromVersion, toVersion: result.toVersion, changeCount: 0, changes: [] }`
   - evidence: `[]`
   - confidence: `'LOW'`

6. Otherwise (structuredChanges has items):
   - answer: `"${result.policyTitle} (${result.payer}): ${result.structuredChanges.length} field changes from v${from_version} to v${to_version}. ${severityCounts.clinical ?? 0} clinical, ${severityCounts.operational ?? 0} operational, ${severityCounts.cosmetic ?? 0} cosmetic changes. ${summary}"`
   - structured_result:
     ```
     {
       policyId: result.policyId,
       policyTitle: result.policyTitle,
       payer: result.payer,
       fromVersion: result.fromVersion,
       toVersion: result.toVersion,
       timestamp,
       summary,
       severityCounts,
       changes: result.structuredChanges.map(c => ({
         field: c.field,
         changeType: c.changeType,
         severity: c.severity,
         rationale: c.rationale,
         oldValue: c.oldValue,
         newValue: c.newValue
       }))
     }
     ```
   - evidence: Extract first 5 non-trivial changes as evidence items:
     ```typescript
     result.structuredChanges
       .filter(c => typeof c.newValue === 'string' && c.newValue.length > 10)
       .slice(0, 5)
       .map(c => ({
         field: c.field,
         text: String(c.newValue).slice(0, 300),
         source: { policy_id: policy_id, policy_title: result.policyTitle, page: 0, section: c.field }
       }))
     ```
   - confidence: `result.structuredChanges.some(c => c.severity === 'clinical') ? 'HIGH' : 'MEDIUM'`

Import `buildPolicyVersionDiff`, `getPolicyChangeEvent` from `../../server/policy-changes.js`. Import `buildStandardResponse`, `buildErrorResponse` from `../utils/response_builder.js`.

Note: `buildStandardResponse` takes (answer, structured_result, evidence, confidence) — the first argument is `answer` (not `human_readable`). Match the StandardToolResponse interface in response_builder.ts exactly.
