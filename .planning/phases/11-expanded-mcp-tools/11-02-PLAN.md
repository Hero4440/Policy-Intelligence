  payer: entry.payer,
  title: entry.title,
  drugFamily: entry.drugFamily,
  currentVersion: entry.currentVersion,
  totalVersions: entry.versions.length,
  versions: [
    {
      version: v,
      fileName: pv.fileName,
      savedAt: pv.savedAt,
      isCurrent: v === entry.currentVersion,
      policyTitle: pv.record.policyTitle ?? pv.record.indication,
      coverageStatus: pv.record.coverageStatus,
      paRequired: pv.record.paRequired
    },
    ...
  ]
}

7. confidence: `'HIGH'`

<task type="auto">
  <name>Task 2: Implement diff_policy_versions MCP tool</name>
  <files>src/mcp/tools/diff_policy_versions.ts</files>
  <action>
Create `src/mcp/tools/diff_policy_versions.ts` exporting `registerDiffPolicyVersions(server: McpServer): void`.

Tool name: `diff_policy_versions`
Description: "Return a structured field-level diff between two versions of a policy. Each changed field includes: field name, old value, new value, change type (added/removed/updated), and severity (cosmetic/operational/clinical). Use this to understand what changed when a policy was updated."

Input schema:
```
{
  policy_id: z.string().describe("Policy ID"),
  from_version: z.number().int().describe("Older version number"),
  to_version: z.number().int().describe("Newer version number")
}
```

Implementation:
1. Import `buildPolicyVersionDiff` from `../../server/policy-changes.js`. This function accepts (policyId: string, fromVersion: number, toVersion: number) and returns a PolicyChangeEvent (see src/storage/types.ts). Consult `src/server/policy-changes.ts` for the exact function signature before implementing.
2. Call `buildPolicyVersionDiff(policy_id, from_version, to_version)`.
3. If null/undefined returned (versions not found), return buildErrorResponse suggesting using list_policy_versions first.
4. If the result has `changes` array that is empty, human_readable should say "No field-level changes detected between v${from_version} and v${to_version}. Changes may be cosmetic (whitespace/formatting only)."
5. Otherwise build response:
   - human_readable: `"${result.policyTitle} (${result.payer}): ${result.changes.length} field changes from v${from_version} to v${to_version}. ${result.severityCounts.clinical ?? 0} clinical, ${result.severityCounts.operational ?? 0} operational, ${result.severityCounts.cosmetic ?? 0} cosmetic changes. ${result.summary}"`
   - structured_result: `{ policyId: result.policyId, policyTitle: result.policyTitle, payer: result.payer, fromVersion: result.fromVersion, toVersion: result.toVersion, timestamp: result.timestamp, summary: result.summary, severityCounts: result.severityCounts, changes: result.changes.map(c => ({ field: c.field, changeType: c.changeType, severity: c.severity, rationale: c.rationale, oldValue: c.oldValue, newValue: c.newValue })) }`
   - evidence: Extract snippets from any change where oldValue or newValue is a string containing evidence text. Map first 5 non-trivial string changes as evidence items with `{ field: c.field, text: String(c.newValue).slice(0, 300), source: { policy_id: policy_id, policy_title: result.policyTitle, page: 0, section: c.field } }`.
   - confidence: result.changes.some(c => c.severity === 'clinical') ? 'HIGH' : 'MEDIUM'
6. Wrap in try/catch → buildErrorResponse on failure.

Note: if buildPolicyVersionDiff throws when versions don't exist, catch that error and return buildErrorResponse.
  </action>
