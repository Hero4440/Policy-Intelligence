**File 1: src/mcp/tools/generate_next_steps.ts**

Export `registerGenerateNextSteps(server: McpServer): void`.

Tool name: `generate_next_steps`
Description: "Generate role-specific next steps for a coverage evaluation. Returns: (1) an ordered clinic next-step action list, (2) a missing documentation checklist with policy evidence, (3) a patient-friendly plain-language explanation, and (4) a payer analyst breakdown of which criteria apply and what evidence satisfies each. Requires a valid evalId from evaluate_patient_against_policy."

Input schema:
```
{
  eval_id: z.string().describe("Evaluation ID returned from evaluate_patient_against_policy")
}
```

Implementation:
1. Call `generateNextSteps(eval_id)` from `../../server/next-steps.js`. This is an async function returning `NextStepsPayload`. Wrap in try/catch.
2. If throws `EvaluationNotFoundError`, return buildErrorResponse("Evaluation not found. Run evaluate_patient_against_policy first.", { hint: "Provide a valid evalId from a previous evaluation." }).
3. Build response:
   - answer: `"Next steps for evaluation ${eval_id}: ${payload.clinicNextSteps.length} action(s), ${payload.missingDocsList.length} missing document(s). ${payload.clinicNextSteps.slice(0, 2).join('. ')}."`
   - structured_result: `{ evalId: payload.evalId, clinicNextSteps: payload.clinicNextSteps, missingDocsList: payload.missingDocsList.map(d => ({ criterion: d.criterion, category: d.category, rationale: d.rationale, policyEvidence: d.policyEvidence })), patientExplanation: payload.patientExplanation, payerAnalystBreakdown: { summary: payload.payerAnalystBreakdown.summary, criteriaAnalysis: payload.payerAnalystBreakdown.criteriaAnalysis } }`
   - evidence: payload.missingDocsList.slice(0, 10).map(d => ({ field: d.criterion, text: d.policyEvidence.snippet, source: { policy_id: '', policy_title: d.category, page: d.policyEvidence.page ?? 0, section: d.policyEvidence.section } }))
   - confidence: payload.missingDocsList.length === 0 ? 'HIGH' : 'MEDIUM'

Import `generateNextSteps`, `EvaluationNotFoundError` from `../../server/next-steps.js`. Import `buildStandardResponse`, `buildErrorResponse` from `../utils/response_builder.js`.

Note: `buildStandardResponse` takes (answer, structured_result, evidence, confidence) — the first argument is `answer` (not `human_readable`). Match the StandardToolResponse interface in response_builder.ts exactly.

**File 2: src/mcp/tools/get_case_summary.ts**

Export `registerGetCaseSummary(server: McpServer): void`.

Tool name: `get_case_summary`
Description: "Get a comprehensive summary of a patient case including patient facts, all coverage evaluations, the most recent evaluation's checklist and coverage status, and next-step guidance. Use this as the entry point for reviewing a patient case holistically."

Input schema:
```
{
  case_id: z.string().describe("Patient case ID"),
  include_next_steps: z.boolean().optional().default(false).describe("Include next step guidance for the most recent evaluation (requires LLM — slower)")
}
```

Implementation:
1. Call `getPatientCase(case_id)` from `../../storage/patient-store.js`. If null, return buildErrorResponse.
2. Call `listEvaluations({ caseId: case_id })` from `../../storage/evaluation-store.js`. This returns CoverageEvaluation[] sorted newest first.
3. `latestEval = evaluations[0] ?? null`
4. Build nextStepsData: if `include_next_steps && latestEval`, call `generateNextSteps(latestEval.evalId)` from `../../server/next-steps.js` (async). Otherwise set to null.
5. Build structured_result:
```
{
  caseId: patientCase.caseId,
  patientName: patientCase.patientName,
  payer: patientCase.payer,
  requestedDrug: patientCase.requestedDrug,
  diagnosis: patientCase.diagnosis,
  status: patientCase.status,
  documentCount: patientCase.documents?.length ?? patientCase.documentFiles.length,
  factCount: (patientCase.extractedFacts ?? []).length,
  evaluationCount: evaluations.length,
  latestEvaluation: latestEval ? {
    evalId: latestEval.evalId,
    policyId: latestEval.policyId,
    policyTitle: latestEval.policyTitle,
    coverageStatus: latestEval.coverageStatus,
    evaluatedAt: latestEval.evaluatedAt,
    checklistSummary: {
      total: latestEval.checklist.length,
      pass: latestEval.checklist.filter(i => i.status === 'PASS').length,
      missing: latestEval.checklist.filter(i => i.status === 'MISSING').length,
      unknown: latestEval.checklist.filter(i => i.status === 'UNKNOWN').length,
      needsReview: latestEval.checklist.filter(i => i.status === 'NEEDS REVIEW').length
    }
  } : null,
  nextSteps: nextStepsData ? {
    clinicNextSteps: nextStepsData.clinicNextSteps,
    missingDocCount: nextStepsData.missingDocsList.length,
    patientExplanation: nextStepsData.patientExplanation
  } : null
}
```
6. answer: `"Case ${case_id} (${patientCase.patientName}): ${(patientCase.extractedFacts ?? []).length} facts, ${evaluations.length} evaluation(s). ${latestEval ? `Latest: ${latestEval.coverageStatus} (${latestEval.policyTitle ?? latestEval.policyId}).` : 'No evaluations yet.'} Status: ${patientCase.status}."`
7. evidence: latestEval?.checklist.slice(0, 5).map(item => ({ field: item.criterion, text: item.policyEvidence.snippet, source: { policy_id: latestEval.policyId, policy_title: latestEval.policyTitle ?? '', page: item.policyEvidence.page ?? 0, section: item.policyEvidence.section } })) ?? []
8. confidence: latestEval ? 'HIGH' : 'LOW'

Import `getPatientCase` from `../../storage/patient-store.js`. Import `listEvaluations` from `../../storage/evaluation-store.js`. Import `generateNextSteps` from `../../server/next-steps.js`. Import `buildStandardResponse`, `buildErrorResponse` from `../utils/response_builder.js`.

Note: `buildStandardResponse` takes (answer, structured_result, evidence, confidence) — the first argument is `answer` (not `human_readable`).
