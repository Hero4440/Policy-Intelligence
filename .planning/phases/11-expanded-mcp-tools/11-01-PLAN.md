  <action>
Create `src/mcp/tools/upload_policy_document.ts` exporting `registerUploadPolicyDocument(server: McpServer): void`.

Tool name: `upload_policy_document`
Description: "Upload a payer medical policy document by file path or URL. Accepts PDF, JSON policy, or CSV formulary. Triggers the full parse-and-store pipeline and returns the structured policy record. Use this when a user wants to add a new policy to the system."

Input schema (zod-shaped object passed to server.registerTool):
```
{
  file_path: z.string().optional().describe("Absolute path to policy file on disk (PDF, JSON, CSV)"),
  url: z.string().optional().describe("URL to download the policy document from"),
  file_name: z.string().optional().describe("Override file name (used when providing URL)")
}
```
Must provide either file_path or url.

Implementation:
1. Validate that at least one of file_path or url is provided. Return buildErrorResponse if neither.
2. If url is provided: use `fetch(url)` to download the file. Read response as ArrayBuffer → Buffer. Derive file_name from the URL path if file_name param not given. Detect mimeType from Content-Type header, falling back to extension.
3. If file_path is provided: use `readFileSync(file_path)` to read the file. Derive file_name from basename. Detect mimeType from extension (.pdf → application/pdf, .json → application/json, .csv → text/csv, else → application/octet-stream).
4. Convert buffer to base64 string.
5. Call `ingestOneFile({ name: fileName, mimeType, base64 })` from `src/server/ingestion/index.ts`.
6. Build response:
   - human_readable: `"Uploaded and processed ${fileName}. Status: ${source.status}. Created ${snapshotCount} policy records."`
   - structured_result: `{ sourceId: source.id, fileName: source.fileName, status: source.status, issuer: source.issuerName, effectiveDate: source.effectiveDate, detectedDrugs: source.detectedDrugs, snapshotCount, notes: source.notes }`
   - evidence: `[]` (ingestion does not return evidence snippets directly)
   - confidence: status === 'normalized' ? 'HIGH' : status === 'partial' ? 'MEDIUM' : 'LOW'
7. Wrap entire handler in try/catch → buildErrorResponse on failure.

Import `readFileSync` from `node:fs`. Import `basename` from `node:path`. Import `ingestOneFile` from `../../server/ingestion/index.js`. Import `buildStandardResponse`, `buildErrorResponse` from `../utils/response_builder.js`. Import McpServer from `@modelcontextprotocol/sdk/server/mcp.js`. Use zod `z` from `zod`.

Do NOT use jsonwebtoken or any auth library. Do NOT call Ollama/LLM — this is a deterministic ingestion tool.

<task type="auto">
  <name>Task 2: Implement parse_policy_document MCP tool</name>
  <files>src/mcp/tools/parse_policy_document.ts</files>
  <action>
Create `src/mcp/tools/parse_policy_document.ts` exporting `registerParsePolicyDocument(server: McpServer): void`.

Tool name: `parse_policy_document`
Description: "Parse an already-stored policy document into structured JSON fields. Use this to re-parse or inspect the structured output of a document already in the system by its source ID or file path. Returns policy fields: payer, drug, indications, prior auth, step therapy, requirements."

Input schema:
```
{
  source_id: z.string().optional().describe("Source ID returned from upload_policy_document"),
  file_path: z.string().optional().describe("Absolute path to a policy text or PDF file to parse directly")
}
```
Must provide either source_id or file_path.

Implementation:
1. If source_id is provided: read the ingestion source record from `data/ingestion/sources/${source_id}.json` using `readFileSync` (safeRead pattern — return buildErrorResponse if not found). Extract extractedTextPath from the record. Read that text file. Call `parsePdfPolicyText({ fileName: source.fileName, text, issuerName: source.issuerName, effectiveDate: source.effectiveDate, knownDrugLexicon: [] })` from `../../server/ingestion/pdf-policy-parser.js`.
2. If file_path is provided: read file with `readFileSync`. If .pdf extension, return buildErrorResponse explaining PDFs must be uploaded first via upload_policy_document (direct binary PDF parse requires the ingestion pipeline). If .txt or .json text file, read as utf-8 string. Call parsePdfPolicyText similarly.
3. Build response:
   - human_readable: `"Parsed policy document. Detected drugs: ${parsedPolicy.drugLabels.join(', ')}. PA required: ${parsedPolicy.priorAuth}. Step therapy: ${parsedPolicy.stepTherapy}."`
   - structured_result: `{ title: parsedPolicy.title, issuer: parsedPolicy.issuerName, effectiveDate: parsedPolicy.effectiveDate, drugLabels: parsedPolicy.drugLabels, priorAuth: parsedPolicy.priorAuth, stepTherapy: parsedPolicy.stepTherapy, quantityLimit: parsedPolicy.quantityLimit, medicalBenefit: parsedPolicy.medicalBenefit, requirementsSummary: parsedPolicy.requirementsSummary, evidenceSummary: parsedPolicy.evidenceSummary, notes: parsedPolicy.notes }`
   - evidence: parsedPolicy.evidenceSummary.map((snippet, i) => ({ field: `evidence_${i}`, text: snippet, source: { policy_id: '', policy_title: parsedPolicy.title, page: 0, section: 'Parsed evidence' } }))
   - confidence: parsedPolicy.drugLabels.length > 0 ? 'MEDIUM' : 'LOW'
4. Wrap in try/catch → buildErrorResponse on failure.

Import `readFileSync`, `existsSync` from `node:fs`. Import `join` from `node:path`. Import `parsePdfPolicyText` from `../../server/ingestion/pdf-policy-parser.js`. Import `buildStandardResponse`, `buildErrorResponse` from `../utils/response_builder.js`.

The ingestion source records live at `data/ingestion/sources/{sourceId}.json` — use `join(process.cwd(), 'data/ingestion/sources', ${source_id}.json)` to build the path.
