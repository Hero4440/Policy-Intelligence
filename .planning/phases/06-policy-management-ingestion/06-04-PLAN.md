  <action>
    Add a new endpoint to the existing `registerPolicyRoutes` function in `src/server/policy-routes.ts`:

    **POST /api/policies/:policyId/versions**
    - Accept JSON body: `{ record: PolicyRecord }` — the full updated PolicyRecord
    - Validate body has `record` field (if not, return 400)
    - Optionally validate with `PolicyRecordSchema.safeParse(record)` — if it fails, return 400 with validation errors
    - Call `savePolicy(policyId, record)` from `../storage/policy-store.js` — this auto-increments the version
    - Return `{ policyId, version: newVersion, savedAt: new Date().toISOString() }` with 201 status
    - On error: return 500 with `{ error: message }`

    Also add `saveVersionedPolicy` as an alias for the frontend to call — just the same savePolicy call.

    This endpoint is the only write path for the editor; the parser in Plan 01 also uses savePolicy on initial upload. Both are idempotent in terms of the storage layer behavior (always creates a new version file and updates the index).

    After adding the endpoint, add a corresponding typed helper to `src/frontend/data/policies.ts`:
    ```typescript
    export async function savePolicyVersion(policyId: string, record: unknown): Promise<{ version: number; savedAt: string }> {
      const res = await fetch(`/api/policies/${policyId}/versions`, {
        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
        body: JSON.stringify({ record })
      });
      if (!res.ok) throw new Error(`Save failed: ${res.status}`);
      return res.json() as Promise<{ version: number; savedAt: string }>;
    }
    ```

    ```typescript
    const POLICY_FIELDS: Array<{ key: string; label: string; type: 'text' | 'boolean' | 'textarea' }> = [
      { key: 'payer', label: 'Payer', type: 'text' },
      { key: 'plan', label: 'Plan', type: 'text' },
      { key: 'policyTitle', label: 'Policy Title', type: 'text' },
      { key: 'indication', label: 'Indication', type: 'text' },
      { key: 'coverageStatus', label: 'Coverage Status', type: 'text' },
      { key: 'paRequired', label: 'Prior Auth Required', type: 'boolean' },
      { key: 'drug.brandName', label: 'Brand Name', type: 'text' },
      { key: 'drug.genericName', label: 'Generic Name', type: 'text' },
    ];
    ```

    **Field row render pattern** (map over POLICY_FIELDS):
    ```
    <article key={field.key} className="detail-card" style={{ display: 'grid', gap: '0.5rem' }}>
      <div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center' }}>
        <p className="detail-card-title">{field.label}</p>
        <label style={{ display: 'flex', alignItems: 'center', gap: '0.25rem', fontSize: '0.75rem' }}>
          <input type="checkbox" checked={ambiguityFlags[field.key] ?? false}
            onChange={e => setAmbiguityFlags(prev => ({ ...prev, [field.key]: e.target.checked }))} />
          Ambiguous
        </label>
      </div>

      {/* Editable value */}
      {field.type === 'boolean' ? (
        <select value={String(getNestedValue(editedRecord, field.key))}
          onChange={e => setNestedValue(field.key, e.target.value === 'true')}>
          <option value="true">Yes</option>
          <option value="false">No</option>
        </select>
      ) : (
        <input type="text" value={String(getNestedValue(editedRecord, field.key) ?? '')}
          onChange={e => setNestedValue(field.key, e.target.value)}
          style={{ width: '100%', padding: '0.25rem 0.5rem', boxSizing: 'border-box' }} />
      )}

      {/* Evidence snippet from record.evidenceSnippets matching field.key */}
      {getEvidenceForField(record, field.key) && (
        <small style={{ color: '#7a9fb4', fontStyle: 'italic' }}>
          Evidence: "{getEvidenceForField(record, field.key)}"
        </small>
      )}

      {ambiguityFlags[field.key] && (
        <small style={{ color: '#e0a800' }}>⚠ Flagged as ambiguous</small>
      )}
    </article>
    ```

    **Helper functions** (private, not exported):
    - `getNestedValue(obj: any, key: string): unknown` — handles dot-notation: `'drug.brandName'` → `obj.drug?.brandName`
    - `setNestedValue(key: string, value: unknown): void` — updates `editedRecord` in state using deep clone; handles dot notation
    - `getEvidenceForField(record: any, fieldKey: string): string | null` — looks in `record.evidenceSnippets` for snippet with matching `field` property, returns `snippet.text?.slice(0, 120)` or null

    **Save handler:**
    ```typescript
    async function handleSave() {
      setIsSaving(true);
      setSaveError(null);
      try {
        const updatedRecord = { ...editedRecord, ambiguityFlags };
        const { version } = await savePolicyVersion(policyId, updatedRecord);
        setSavedVersion(version);
        onSaved(policyId, version);
      } catch (err) {
        setSaveError(err instanceof Error ? err.message : 'Save failed');
      } finally {
        setIsSaving(false);
      }
    }
    ```

    ```
      </div>
      <button className="page-nav-btn page-nav-btn-active" onClick={handleSave} disabled={isSaving}>
        {isSaving ? 'Saving...' : 'Save New Version'}
      </button>
    </div>

    {saveError && <div className="chat-error">{saveError}</div>}
    ```
