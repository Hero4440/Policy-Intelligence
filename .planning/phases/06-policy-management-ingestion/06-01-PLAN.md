<task type="auto">
  <name>Task 1: PDF-to-PolicyRecord parser</name>
  <files>src/server/policy-parser.ts</files>
  <action>
    Create `src/server/policy-parser.ts` that exports `parsePdfToPolicy(buffer: Buffer, fileName: string): Promise<PolicyRecord>`.

    Implementation steps:
    1. Use `pdf-parse` (already in package.json) to extract raw text from the buffer: `import pdfParse from 'pdf-parse'`; call `await pdfParse(buffer)` to get `{ text }`.
    2. Split text into lines, trim, filter empty. Detect the following fields via regex/heuristics (reuse patterns from `src/server/ingestion/pdf-policy-parser.ts` for title/issuer/date/drug detection):
       - `payer`: look for line matching known payer names or fallback to fileName slug
       - `plan`: look for "Plan" keyword near title or default to "Standard"
       - `policyTitle`: first meaningful title line (≥10 chars, mixed case)
       - `indication`: look for "indication" or "Indication" header lines
       - `coverageStatus`: default to `'covered'` unless "not covered" or "denied" found
       - `paRequired`: `true` if text contains "prior authorization" case-insensitively
       - `drug.brandName` / `drug.genericName`: detect using `normalizeDrugName` from `data/lookup/drug-aliases.js`
       - `indications`: collect lines under "Indication" or "Covered" sections (up to 5)
       - `diagnosisRequirements`: empty array (not extractable reliably from raw PDF in v2.0)
       - `stepTherapy`: object with `required: boolean` from "step therapy" presence, `details: string[]` from adjacent lines
       - `otherRequirements`: lines under "Other Requirements" or "Additional Criteria" (up to 5)
       - `evidenceSnippets`: array of { field, text, page, section } — collect 3–5 snippets: first para, PA section para, step therapy para, indication section para
       - `sourceDocument`: `{ fileName, uploadedAt: new Date().toISOString(), pageCount: data.numpages }`

    3. Compose and return a PolicyRecord matching the schema in `data/schemas/policy.schema.js`. Validate with `PolicyRecordSchema.safeParse()` — if it fails, log the errors and return a minimal valid record with extracted text as a note in `otherRequirements`.

    Use `.js` import extensions (ESM project). Import `normalizeDrugName` from `'../../data/lookup/drug-aliases.js'`.
    Export only `parsePdfToPolicy`.
  </action>
  <verify>Run `npx tsc --noEmit` — zero type errors in policy-parser.ts</verify>
  <done>parsePdfToPolicy compiles without errors and exports a function accepting Buffer + filename returning Promise&lt;PolicyRecord&gt;</done>
</task>

<task type="auto">
  <name>Task 2: Policy upload and list API routes</name>
  <files>src/server/policy-routes.ts, src/server/index.ts</files>
  <action>
    Create `src/server/policy-routes.ts` exporting `registerPolicyRoutes(app: Express): void`.

    Register these endpoints:

    **POST /api/policies/upload**
    - Accept JSON body: `{ fileName: string, contentBase64: string }` — content is base64-encoded PDF bytes
    - Decode: `Buffer.from(contentBase64, 'base64')`
    - Call `parsePdfToPolicy(buffer, fileName)` from `./policy-parser.js`
    - Generate policyId: `slugify(policyTitle + '-' + payer)` using a simple regex-replace (lowercase, spaces→hyphens, strip non-alphanumeric except hyphens)
    - Call `savePolicy(policyId, record)` from `../storage/policy-store.js` — this handles versioning and index update
    - Save raw PDF to `data/policies/raw/` via `saveRawPolicyFile(policyId, buffer, fileName)` from the policy-store (add this export to policy-store.ts if not present — write a simple fs.writeFileSync to `POLICIES_RAW_DIR/{policyId}/{fileName}` with `mkdirSync({ recursive: true })`)
    - Return `{ policyId, version: savedVersion, record }` with 201 status

    **GET /api/policies**
    - Call `loadIndex()` from `../storage/policy-store.js`
    - Return `{ policies: index.policies }` — this is the PolicyIndex.policies array

    **GET /api/policies/:policyId**
    - Accept optional query param `?version=N`
    - Load the specific version file from disk using `loadPolicyVersion(policyId, version)` — add this export to policy-store.ts: reads `POLICIES_STRUCTURED_DIR/{policyId}_vN.json` and returns PolicyVersion or null
    - If version not specified, use `currentVersion` from index entry
    - Return `{ entry, record }` or 404

    **GET /api/policies/:policyId/versions**
    - Load index, find entry, return `{ versions: entry.versions, currentVersion: entry.currentVersion }`

    In `src/server/index.ts`: add `import { registerPolicyRoutes } from './policy-routes.js';` and call `registerPolicyRoutes(app)` alongside the existing route registrations.
  </action>

    - Upload a test PDF: encode a small PDF as base64 and POST to /api/policies/upload — verify 201 response with policyId
    - `curl http://localhost:3000/api/policies` shows the uploaded policy in the list
  </verify>
